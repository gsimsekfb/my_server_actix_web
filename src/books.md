### If you only want 2 books

**1. Designing Data-Intensive Applications (DDIA)**
Best overall foundation. Covers:

* Database design
* Indexes
* Transactions & consistency
* Replication
* Partitioning
* Distributed systems
* Caching concepts
* Queues/streams
* Scalability

**2. System Design Interview – Vol 1 & 2 (Alex Xu)**
Much more interview-oriented:

* REST/API design
* Load balancing
* Caching
* Redis-like concepts
* DB scaling
* Queues
* Horizontal scaling
* Real system-design examples

### One important caveat

**None of these is a great dedicated Redis + SQL interview book.** For your exact list, I'd combine:

> **DDIA → Alex Xu → SQL practice → Redis documentation/practice**
